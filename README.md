# Dental Branding Pro — L'Écosystème Numérique pour Cabinets Dentaires

**Dental Branding Pro** est une plateforme web haut de gamme, moderne, ultra-rapide et responsive, spécialement conçue pour les chirurgiens-dentistes et cabinets dentaires au Maroc.

---

## 🌟 Fonctionnalités Principales

- ⚡ **Site Web Ultra-Rapide (< 0.8s) :** Score PageSpeed 99/100 sur mobile.
- 📱 **Diagnostic Dentaire TInteractif & Prise de RDV WhatsApp :** Redirection dynamique et directe vers le WhatsApp officiel du cabinet.
- 💳 **Carte DentaLink NFC & QR Code :** Carte de visite virtuelle interactive avec bouton d'urgence et enregistrement vCard.
- 🎙️ **Podcast Audio & Synthèse 60s :** Mode immersif audio et synthèse exécutive pour les praticiens.
- 🛡️ **Conformité Déontologique :** 100% conforme au Code de Déontologie de l'Ordre National des Médecins Dentistes du Maroc.
- 🌐 **Multilingue (Arabe & Français) :** Bascule instantanée entre le Français et l'Arabe.

## 🚀 Démarrage Rapide en Local

### 1. Prérequis
- Node.js (v18+)
- npm ou yarn

### 2. Installation
```bash
# Cloner le dépôt
git clone https://github.com/votre-nom-utilisateur/dental-branding-pro.git

# Accéder au dossier
cd dental-branding-pro

# Installer les dépendances
npm install
```

### 3. Lancement en Mode Développement
```bash
npm run dev
```
Le serveur local démarre généralement sur `http://localhost:3000`.

### 4. Compilation pour Production
```bash
npm run build
```
Les fichiers statiques optimisés seront générés dans le dossier `dist/`.

## 📦 Déploiement sur GitHub Pages

### Option 1 : Déploiement Automatique via GitHub Actions (Recommandé)
1. Créez un nouveau dépôt sur **GitHub**.
2. Pushez votre code source sur la branche `main`.
3. Allez dans **Settings > Pages** de votre dépôt GitHub.
4. Dans **Source**, sélectionnez **GitHub Actions** (choisissez le workflow Static HTML / Vite).

### Option 2 : Déploiement du Dossier `dist`
1. Exécutez `npm run build`.
2. Déposez le contenu du dossier `dist/` sur le service d'hébergement de votre choix (GitHub Pages, Netlify Drop, Vercel).
